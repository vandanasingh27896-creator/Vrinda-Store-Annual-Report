This project is an interactive sales dashboard
created using Microsoft Excel.

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization

## Dashboard Analysis

- Order Status
- Top 5 States
- Age vs Gender
- Sales Channels
- Monthly Sales Trends
